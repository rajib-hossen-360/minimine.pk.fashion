# minimine.pk.fashion

Modern, high-performance Kids Fashion & Apparel e-commerce web application inspired by Minimine PK and branded as Webnibo. Built with Next.js 13 (App Router), TypeScript, Tailwind CSS, and Lucide Icons.

## Features
- **Hero Slider**: Auto-advancing slides highlighting seasonal arrivals & collections.
- **Showcase Tabs**: Quick navigation through Girls, Boys, Infant, and Sale categories.
- **Dynamic Category Pages**: Rich filtering (price, category, availability) and sorting with responsive layouts.
- **Interactive Review Carousel**: Single-card Facebook-style verified customer reviews with prev/next arrow navigation and touch swipe.
- **Quick View Modal & Size Guide**: Instant product previews and comprehensive measurement charts.
- **Cart & Wishlist Drawers**: Slide-over cart and wishlist management with real-time total updates.
- **Mobile Optimized**: Custom bottom navigation, drawer menus, responsive grids, and touch-friendly controls.

## Tech Stack
- **Framework**: [Next.js 13](https://nextjs.org/) (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Vanilla CSS
- **Icons**: Lucide React
- **Package Manager**: pnpm

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/rajib-hossen-360/minimine.pk.fashion.git
cd minimine.pk.fashion
```

2. Install dependencies:
```bash
pnpm install
```

3. Run the development server:
```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
